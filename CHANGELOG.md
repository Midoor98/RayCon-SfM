# Changelog

## v0.1.0 — 2026-09-20

First versioned public preview of RayCon-SfM.

### Added

- Standalone C++17 feature-track organization and JSON/CSV export.
- CMake Release build, command-line version reporting and input validation.
- Cross-checks against the existing Python public utility.
- Deterministic synthetic showcase data and a reproducible preview image.
- Concept cover artwork, quick start, input reference and a tentative December 2026 roadmap.

### Scope

This release contains standalone public utilities. It does not provide an end-to-end SfM backend. All bundled input is synthetic. The cover is concept artwork, and no benchmark claim is made.
